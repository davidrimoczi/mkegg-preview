# M/KE website

Independent esports media. Built with [Astro](https://astro.build), edited with [Pages CMS](https://pagescms.org), hosted on GitHub Pages.

- Articles: `src/content/articles/*.md` (or use the Pages CMS editor)
- Brand: logo in `src/components/Wordmark.astro`, colours and type in `src/styles/global.css`
- Preview: https://davidrimoczi.github.io/mkegg-preview (drafts visible, hidden from search)
- `legacy-coming-soon/`: the original Coming Soon page, kept for reference

Run locally: `npm install`, then `npm run dev`.
